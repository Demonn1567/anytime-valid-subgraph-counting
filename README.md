# Anytime-Valid Subgraph Counting

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24530637.svg)](https://doi.org/10.5281/zenodo.24530637)

Archived release (v1.0.0): https://doi.org/10.5281/zenodo.24530637

Code, tests, exact ground truth and raw per-run results for the WSDM 2027 paper

> Krish Sharma and Jatin Bedi. *Anytime-Valid Subgraph Counting: Confidence
> Sequences and Adaptive Stopping for Sampling-Based Estimation.* In
> Proceedings of the Twentieth ACM International Conference on Web Search and
> Data Mining (WSDM 2027).

Every number, table and figure in the paper is generated by
`make_paper_artifacts.py` from the raw result files in `results_cr/`; nothing
in the paper is transcribed by hand.

## Installation

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Tested with Python 3.9.6 on macOS (Apple M4, CPU only).

## Layout

```
avsc/
  cs_arms.py        the four confidence sequences (betting / closed form x
                    empirical Bernstein / Hoeffding); power-sum evaluation of
                    the betting capital with certified truncation bounds
  run_loop.py       one sample stream, five monitors, one stopping rule;
                    the naive Wald peeking monitor
  fast_samplers.py  CSR graph; wedge sampler (triangles); edge sampler
                    (k-cliques); their preprocessing
  realgraphs.py     loaders for jazz, PGP, C. elegans, power (auto-download)
  bigraphs.py       loaders for the five SNAP graphs (auto-download)
tests/              correctness tests
tools_gt/           exact k-clique ground truth (kClist and Pivoter)
prep_edge_cache.py  caches each graph; checks it edge by edge against the
                    ground-truth edge lists
run_cr_grid.py      triangle study: 9 graphs x 2 targets x 80 runs
run_cr_cliques.py   k-clique study: 6 graphs x k=3..6 x 2 targets x 80 runs
run_cr_baselines.py fixed-budget Hoeffding and oracle fixed-n EB baselines
run_cr_timing.py    single-process wall-clock measurement (run alone)
run_cr_clique_cost.py  k-clique sampler cost and range bounds (run alone)
prpl_prediction.py  deterministic surrogate for closed-form stopping times
analysis_cr.py      summaries: coverage over all runs, Wilson intervals
make_paper_artifacts.py  every table, figure and number in the paper
results_cr/         raw per-run results used in the paper
```

## Reproducing the paper

```bash
# 1. Tests
.venv/bin/python tests/test_cs_arms.py        # engine vs reference implementations; Monte Carlo coverage
.venv/bin/python tests/test_run_loop.py       # batched evaluation == evaluation in steps of 100
.venv/bin/python tests/test_fast_samplers.py  # exact sampler distributions; unbiasedness (downloads graphs)

# 2. Ground truth. Build kClist (https://github.com/maxdan94/kClist, commit 54eb3a2)
#    and Pivoter (https://github.com/sjain12/Pivoter, commit 9be1880) in ../tools/kClist
#    and ../tools/Pivoter, i.e. a folder "tools" next to this repository. Then:
.venv/bin/python tools_gt/export_edgelists.py
tools_gt/run_counters.sh                      # kClist
tools_gt/run_pivoter.sh                       # Pivoter
.venv/bin/python tools_gt/build_ground_truth.py   # requires exact agreement of both tools
# Exact edge-sampler variances need Pivoter's per-edge counts, from tools_gt/:
#   mkdir -p results && for g in jazz pgp celegans power com-dblp com-amazon; do
#     ../../tools/Pivoter/bin/degeneracy_cliques -i edgelists/$g.edges -t E -k 6 -d 1; done
.venv/bin/python tools_gt/exact_sampler_variances.py
.venv/bin/python prep_edge_cache.py

# 3. Experiments (results already included in results_cr/)
.venv/bin/python run_cr_grid.py 8             # triangle study
.venv/bin/python run_cr_cliques.py 8          # k-clique study
.venv/bin/python run_cr_baselines.py 2        # baselines (after run_cr_grid.py)
.venv/bin/python run_cr_timing.py             # wall clock (nothing else running)
.venv/bin/python run_cr_clique_cost.py 1      # sampler cost (nothing else running)

# 4. Every table, figure and number in the paper
AVSC_PAPER_DIR=paper .venv/bin/python make_paper_artifacts.py
```

Settings: alpha = 0.10, warm-up 100 samples, monitoring every 100 samples,
bet cap 1/2, 80 runs per cell, sample cap 3e8 (triangles) and 2e7
(k-cliques), no wall-clock cap. Every result row records its seed. Step 4
needs only the cached graphs from step 2 and the included results.

## Data and third-party tools

The graphs are downloaded at first use from their public sources (SNAP and
the NetworKit input collection) and are not redistributed here. kClist and
Pivoter (GPL-3.0) are not included; the counts we obtained are in
`tools_gt/ground_truth_kcliques.csv`, with the raw tool output in
`tools_gt/gt_logs/`.
